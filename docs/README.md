# Docs

- `tasks/` — what to build and why, one file per task (`NNNN-slug.md`).
- `plan/` — the approach for a task, written before implementing it; shares the task's number.
- `adr/` — architecture decision records. Immutable once accepted: a changed decision gets a new ADR that supersedes the old one.
- `arch/` — the current shape of the system (`overview.md`), kept up to date as the code changes.
